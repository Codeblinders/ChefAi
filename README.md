# Chef AI 🍳🤖

Chef AI is an AI-powered web application that provides personalized food recipes based on user preferences and available ingredients. Whether you're looking for a quick snack or a gourmet meal, Chef AI helps you whip up the perfect dish effortlessly!

## 🚀 Features

- **AI-Powered Recipe Generation:** Get custom recipes tailored to your taste and available ingredients.
- **User-Friendly Interface:** Easily navigate through the app to find recipes and cooking instructions.
- **Ingredient-Based Search:** Input the ingredients you have, and Chef AI suggests dishes you can make.
- **Responsive Design:** Works seamlessly across desktops, tablets, and mobile devices.

## 🛠️ Technologies Used

- **Frontend:** ReactJS
- **Backend:** Node.js, Express.js
- **AI Integration:** AI API for recipe generation
- **Styling:** CSS/Styled Components (or specify if you're using any frameworks like TailwindCSS)
  
## 📦 Installation

1. **Clone the repository:**

    ```bash
    git clone https://github.com/sahil00016/chef-ai.git
    cd chef-ai
    ```

2. **Install dependencies for both frontend and backend:**

    ```bash
    # For frontend
    cd client
    npm install

    # For backend
    cd ../server
    npm install
    ```

3. **Set up environment variables:**

    Create a `.env` file in the root directory of the server and add your API keys:

    ```env
    AI_API_KEY=your_api_key_here
    PORT=5000
    ```

4. **Run the application:**

    ```bash
    # Run backend
    cd server
    npm start

    # In a new terminal, run frontend
    cd ../client
    npm start dev
    ```
